# Medical Automated Data Analysis System

A final-year Computer Science project demo for managing laboratory test results and performing rule-based reference-range flagging.

## Demo
This version is a self-contained frontend demo using HTML, CSS and JavaScript with browser localStorage. No server or database installation is required.

## Run
Open `index.html` in a modern browser.

## Features
- Demo login
- Dashboard
- Patient registration/search
- Laboratory test/reference-range management
- Result entry
- LOW / WITHIN RANGE / HIGH classification
- Patient history and trend chart
- Report preview
- User management
- Audit activity
- Responsive design

## Important
This application is an academic/demo decision-support system. Automated flags are not medical diagnoses. Use validated laboratory-specific reference intervals and qualified professional review for real clinical use.
